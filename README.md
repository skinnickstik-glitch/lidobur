# ЛиДоБур — персональное демо

Копия калькулятора скважин для бригады **ЛиДоБур** (Карелия, [группа ВК](https://vk.ru/club212290214)).

- Калькулятор: глубина до скалы (обсадка стальной трубой) + бурение в скале + опция пластиковой трубы + одно из трёх обустройств.
- Все цены — «от», итог ориентировочный. В обустройстве в прайсе указана работа.
- Хранилище: IndexedDB `lidobur-demo`, кэш `lidobur-v1`. PIN кабинета: `1234`.
- Контакт в интерфейсе — только ссылка на их ВК, телефон и адрес бригады не указаны.

Публикация: https://skinnickstik-glitch.github.io/lidobur/
